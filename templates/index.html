Capture Live Traffic

?How to enable live capture
  1. Install Wireshark's capture tool, dumpcap: sudo apt install wireshark-common (Debian, Ubuntu) or sudo dnf install wireshark-cli (Fedora, RHEL). On Debian and Ubuntu, answer "Yes" when asked whether non-superusers should be able to capture packets, or run sudo dpkg-reconfigure wireshark-common to change it.
  2. Let pyLot's account, {{ capture_user }}, capture: sudo usermod -aG wireshark {{ capture_user }}
  3. Group changes only reach programs started after you log in again, so log out and back in, then restart pyLot. Without logging out, start pyLot with the group from your current shell: sg wireshark -c "venv/bin/python app.py". id lists your groups; wireshark should be among them.
  4. If pyLot runs as a systemd service, add SupplementaryGroups=wireshark to its unit instead.

Don't run pyLot as root to get around this; dumpcap is the only part that needs capture rights.

How it works

Each upload becomes a session. pyLot maps the hosts and conversations in the capture and classifies devices with GRASSMARLIN's fingerprints: Modbus, DNP3, BACnet, EtherNet/IP, S7, IEC 104, PROFINET and over a hundred more industrial and IT protocols and vendors.
